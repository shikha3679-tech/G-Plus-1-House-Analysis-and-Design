# Revit – 3D BIM Modeling

This section contains the 3D Building Information Modeling (BIM) of the G+1 residential building developed using Autodesk Revit.

## Software Used

- Autodesk Revit

## Contents

- 3D architectural model
- Ground floor model
- First floor model
- Walls, doors, windows and floors
- Building views and elevations

## Files

- `G+1_House_Model.rvt` – Revit model of the G+1 residential building
- `3D_View.pdf` – 3D model views
- `Elevations.pdf` – Building elevation drawings
- `Sections.pdf` – Building section drawin

## Description

The G+1 residential building was modeled in Autodesk Revit to develop a complete 3D BIM model. 
The model includes the main architectural components such as walls, floors, doors, windows and other building elements. 
Different views, elevations and sections were generated from the BIM model.
