# STAAD.Pro – Structural Analysis and Design

This section contains the structural analysis and design of the G+1 residential building performed using STAAD.Pro.

## Software Used

- STAAD.Pro

## Structural Components

The structural model includes:

- Columns
- Beams
- Slabs
- Supports
- Load combinations

## Analysis

The building structure was analyzed for different loading conditions, including:

- Dead Load
- Live Load
- Load Combinations

## Files

- `G+1_House_Model.std` – STAAD.Pro structural model
- `Analysis_Results.pdf` – Structural analysis results
- `Design_Results.pdf` – RCC design results

## Description

The structural model of the G+1 residential building was developed in STAAD.Pro. Appropriate material properties,
member dimensions, supports and loading conditions were assigned to the structure. The model was analyzed to
obtain forces, moments, displacements and other structural responses.
The structural members were then checked and designed based on the analysis results.
